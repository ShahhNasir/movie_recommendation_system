# 🎥 Movie Recommendation System

Welcome to the **Movie Recommendation System**! This project is designed to deliver personalized movie suggestions, combining the power of data science and machine learning. Dive in and discover how AI can enhance your movie-watching experience. 🍿

---

## 🌟 Project Overview
This system intelligently recommends movies based on user preferences using advanced filtering techniques. It’s perfect for cinephiles who love exploring new movies tailored to their tastes.

## 🚀 Installation

### Prerequisites
Ensure you have the following installed:
- Python 3.8 or above
- Jupyter Notebook
- Flask

### Setup Steps
1. **Clone the repository**:
   ```bash
   git clone https://github.com/ShahhNasir/movie_recommendation_system.git
   cd ShahhNasir-movie_recommendation_system
   ```
2. **Create a virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

---

## 🎯 Usage

### Running the Application
1. Start the Flask app:
   ```bash
   python app.py
   ```
2. Open your browser and visit: `http://127.0.0.1:5000`

### Exploring the Jupyter Notebook
1. Open the notebook:
   ```bash
   jupyter notebook notebook.ipynb
   ```
2. Follow the steps in the notebook for data exploration and model building.
